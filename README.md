# ZonoePatch V3 — Floating Icon

Independent iOS 14+ arm64 UIKit/Theos floating icon proof of concept.

- 56pt draggable Z icon, edge snapping and safe-area bounds
- Touch pass-through outside icon, window-scene aware
- Tap opens a test dialog
- No IL2CPP, Hook or Patch engine included

Branch based on main, independent of V2 dev branch. CI artifacts are not proof of device execution.
